# Copilot UX Components

This folder contains reusable samples that demonstrate how to build interactive user experiences in Microsoft Copilot using Copilot UX components.

Each sample focuses on a specific UX component or interaction pattern and is maintained in its own folder. These samples show how interactive components can present information, collect user input, and support actions directly within a Copilot conversation.
