# servicenow-catalog-copilot

SPFx 1.24 Copilot UX component and declarative agent for the ServiceNow catalog.
See the [solution README](../README.md) for architecture, deployment and testing.

- `npm run build` - test, bundle and package (`sharepoint/solution/servicenow-catalog-copilot.sppkg`)
- `npx heft start --nobrowser` - serve locally for the Copilot Workbench
